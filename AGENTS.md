# Working with Made in Dilan

For content ideas, scripts, filming, editing, platform adaptations, and production tasks, read and apply `.agents/skills/made-in-dilan-content/SKILL.md`.

New user instructions take priority. Use existing briefs and decisions instead of asking for them again. Keep quick-recording requests small. Present a compact production table and tasks with observable completion criteria.

Repository documentation is English. Generated content follows the language requested in the brief, or the language of the user's brief when unspecified.

Separate project facts, proposed spoken lines, and unconfirmed reasoning. Source material and facts about the user are different kinds of evidence. Reading files or transcripts does not establish that the video itself was watched.
