# 1. Start with an idea

**Raw idea:** “I want to show how I use Content Planner to prepare a video.”

**Real project:** this Content Planner repository.  
**Audience:** designers and independent creatives with work to share.  
**Available material:** the README, skill instructions, production template, and the output files saved in this demo.

## Prompt used

```text
$made-in-dilan-content

Help me turn this idea into one Instagram Reel:
“I want to show how I use Content Planner to prepare a video.”

Use this repository as the real project. I can appear on camera and
screen-record its files. Keep the first piece around 40 seconds.

Write in English. Give me one main thought, a short plan, a table
matching spoken words to visuals and editing notes, and ordered tasks.

Use only the facts in the repository. Mark spoken lines as drafts.
```

## What this brief makes explicit

One platform, one first piece, a real audience, existing source material, and a preference to appear on camera.
